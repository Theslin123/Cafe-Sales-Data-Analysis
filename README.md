# Cafe-Sales-Data-Analysis
# Project Overview

This project involves cleaning and analyzing a transaction dataset using Microsoft Excel. The goal was to improve data quality, organize the data, and create Pivot Tables and Pivot Charts to understand spending patterns.

Data Cleaning

I performed the following data cleaning steps:

* Identified and checked missing values.
* Corrected errors in the dataset.
* Filled missing values where appropriate.
* Filled missing transaction dates by referring to the dates above and below the blank cells.
* Checked and handled missing or incomplete records.
* Organized the dataset for analysis.

Pivot Table Analysis

I created Pivot Tables to summarize and analyze the data, including:

* Total spending by location.
* Average spending by location.
* Counted transactions by payment method.
* Spending patterns across different categories.
* Sales by payment method.
* Monthly sales.
* Total quantity sold by each item.

Pivot Charts

I created Pivot Charts to visualize the summarized data:

* Column chart - sales by item, quantity sold by item. 
* Bar chart - sales by location, average spending by location.
* Pie chart - sales by payment method.
*	Line chart - monthly sales trends.
*	Donut chart - Transactions by payment method.


Tools Used

* Microsoft Excel
    * Data Cleaning
    * Pivot Tables
    * Pivot Charts
    * Data Visualization

Project Outcome

This project helped me practice data cleaning, data summarization, and data visualization using Excel. It also helped me understand how to turn raw transaction data into meaningful insights.
